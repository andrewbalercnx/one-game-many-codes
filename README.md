# One Game, Many Codes

A static site about how the football codes evolved from small differences in their
rules. Pages are build-time views over the typed content repository in `/content/`
(entity schemas per `docs/one-game-many-codes-mvp-design-brief.md` §3). Design and
process are governed by `DESIGN.md` and `LOOP.md`.

## Build

    make build          # or: python3 build/build.py

Requires Python 3 with PyYAML. A blocking content lint (the round-relevant subset of
MVP brief §7) runs first; a failing check aborts the build. Output is written to
`dist/` — committed here so the design surface can review rendered output on GitHub,
and regenerated by the build.

## Round 2 slice

- `dist/1925-offside-two-defenders.html` — the 1925 experiment page (statute-card debut).
- `dist/possession-limits.html` — the possession-limits rule page (positions strip; the
  `On the pitch` / `In the stands` sections).
- `dist/index.html` — a placeholder landing (the designed Home comes later).

## Verification

The build prints the number of seed facts marked `verified: false` — 20 at round 2 —
for the author's verification pass. Nothing is asserted as sourced until then; the
statute card renders quoted law text with an `unverified` marker.
